TripApp ilk düzeltme paketi

Önce proje klasörünün yedeğini alın. ZIP içeriğini proje kök dizinine çıkarıp dosyaların üzerine yazın.

Sonra proje kökünde çalıştırın:
flutter pub get
flutter analyze
flutter test
flutter build apk --debug

Not: Bu kaynak paketi burada Flutter SDK ile derlenmedi. Test sonuçları görülmeden derlemenin başarılı olduğu iddia edilmez.
